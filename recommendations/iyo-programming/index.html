QUREOは「導入教材」として確認する

QUREOは教室そのものの名称ではなく、各教室が導入するプログラミング教材・カリキュラムです。教材が同じでも、講師の関わり方、振替制度、開講枠、費用は教室ごとに異なります。公式運営元と誤認しないよう、申し込み先と契約条件は各教室単位で確認してください。

体験授業で確認したい6項目

  1. 対象学年：現在の学年で受講できるか
  2. コース：初級修了後にどこまで学べるか
  3. 総費用：月謝・入会金・教材費・機器利用料を含む初年度総額
  4. 指導方法：困ったときに講師がどう支援するか
  5. 振替・休会：欠席時の対応や退会条件
  6. 通いやすさ：実際の時間帯の交通量、駐車・送迎場所
