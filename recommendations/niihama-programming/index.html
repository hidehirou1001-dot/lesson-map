目的別に見る選び方

作品制作と学べるツールを重視したい

DCプログラミングスクールは、公式サイトでScratchとUnityを使用ツールとして掲載しています。Scratchではゲームやアニメーション制作、Unityでは2D・3Dゲーム制作を扱います。低学年の場合は、体験時に現在のコースと進度を確認しましょう。

料金と通学頻度を先に比較したい

DCプログラミングスクールは、60分・90分授業と月2回・月4回の料金を公開しています。月謝だけでなく、入会金11,000円とScratch教材費が別途必要です。QUREO導入2教室は、最新料金を各教室へ問い合わせて同じ条件で比べましょう。

新居浜駅からの通いやすさを重視したい

明光義塾 新居浜中央教室はJR新居浜駅から徒歩5分と案内されています。電車利用だけでなく、送迎時の停車場所や夕方の交通量も体験日に確認すると安心です。

萩生周辺の生活動線で探したい

明光義塾 新居浜中萩教室は、県立新浜病院近く、ファミリーマート隣と案内されています。新居浜中央教室と対象学年・対応コースは共通ですが、開講枠や料金は教室ごとに確認が必要です。

教材名と教室名を分けて考える

Scratchはプログラミング学習環境、QUREOは各教室が導入する教材・カリキュラムです。同じ教材でも、講師の支援、開講枠、振替、料金は教室ごとに異なります。名称を見ただけで授業内容が同じと判断せず、契約先となる教室の条件を確認してください。

体験で確認したい6項目

  1. 対象と開始段階：現在の学年・経験でどこから始めるか
  2. 制作内容：ゲーム、アニメーション、検定など本人の目的と合うか
  3. 指導方法：つまずいたときに講師がどう支援するか
  4. 初年度総額：月謝、入会金、教材費、機器利用料を含める
  5. 振替・休会：欠席時と長期休暇中の扱い
  6. 通学：実際の曜日・時間帯に無理なく送迎できるか
