教材名だけで教室を決めない

有名な教材でも、子どもの興味や学び方に合うとは限りません。完成手順を追う時間と自由に試す時間の割合、分からないときの先生の支援、授業後に子ども自身が「何を作ったか」を説明できるかを見ると、相性を判断しやすくなります。

体験で確認する6項目

  1. 対象：現在の学年とパソコン経験に合うか
  2. 興味：教材や制作課題に集中できているか
  3. 指導：答えを教えるだけでなく考える時間があるか
  4. 進級：基礎の先にどのような教材や学びがあるか
  5. 費用：月謝、入会金、教材・端末・検定費を含む総額
  6. 通学：曜日、振替、送迎、駐車場を含めて続けられるか
