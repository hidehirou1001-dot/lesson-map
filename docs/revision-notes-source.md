# LessonMap 修正メモの参照先

サイト改善の依頼・優先度・対応状況は、次のGoogleスプレッドシートを一次参照先として扱う。

- [Codex 修正メモ](https://docs.google.com/spreadsheets/d/1lSfolkEgW8b2PpHzBE7EilE0jCb3SatnCdzOkTr2_i8/edit?gid=1758935672#gid=1758935672)
- 対象タブ: `修正メモ`（sheetId: `1758935672`）

## 反映時の確認

1. 実装前に対象行の「修正内容」「優先度」「ステータス」「Codexメモ」を確認する。
2. 既存実装がある場合も、項目の存在だけでなく修正意図を満たしているか確認する。
3. サイト側の変更後は、関連する導線、表示件数、スマートフォン表示、内部リンクを確認する。
4. 実装を開始したら必要に応じてステータスを「対応中」にし、サイト反映後は「確認待ち」または「完了」へ更新する。
5. ステータス更新時は、`Codexメモ`へ実装内容・確認事項・関連コミットを簡潔に記録する。
6. 判断保留や対応対象外は、理由を`Codexメモ`へ残したうえで「見送り」にする。

## ステータス運用

- `未対応`: まだ確認・着手していない
- `AI提案`: 改善案があり、実装判断または着手を待っている
- `対応中`: 現在実装・検証している
- `確認待ち`: 実装済みで、ユーザーまたは本番表示の確認を待っている
- `完了`: 実装・反映・必要な確認が完了している
- `見送り`: 今回は対応しないと判断し、理由をメモに残している
