# LessonMap Decision Support Strategy

LessonMapは、単なる教室・講座の掲載サイトではなく「自分や家族に合った学び方を見つけるための意思決定支援サービス」を目指す。

## 目指す状態

ユーザーがLessonMapを使ったあとに、次の判断ができる状態を作る。

- 何を学ぶべきか
- どの学び方が合いそうか
- どの条件なら続けられそうか
- どこで比較すべきか
- 体験・申込前に何を確認すべきか

掲載数を増やすこと自体を目的にしない。掲載情報、記事、比較UI、保存機能はすべて「選ぶ理由を作る」ために使う。

## 対象とする学習ニーズ

| 領域 | 主なユーザー | 意思決定で迷うこと |
| --- | --- | --- |
| 子どもの習い事 | 保護者、子ども | 年齢に合うか、送迎できるか、続けられるか |
| 大人の習い事 | 社会人、シニア | 初心者でも入りやすいか、生活に入るか |
| セミナー | 学び直し層、保護者、ビジネス層 | 単発で得たい知識に合うか |
| 勉強会 | 実践者、仲間を探す人 | レベル感、交流のしやすさ、継続性 |
| ワークショップ | 親子、初心者、体験重視層 | 体験して判断できるか |
| オンライン講座 | 忙しい人、県外講師も見たい人 | 時間・場所に縛られず続けられるか |
| 資格学習 | キャリア・受験・転職層 | 合格までの道筋、サポート、費用感 |
| AI・IT学習 | 子ども、大人、リスキリング層 | 初心者向けか、実務につながるか |
| ビジネススキル | 社会人、個人事業主 | 実践に使えるか、短期で学べるか |
| 語学学習 | 子ども、大人、資格目的 | 会話か試験か、対面かオンラインか |
| 副業・キャリア学習 | 社会人、主婦・主夫、転職層 | 収益化・転職・実務に近いか |

## LessonMap独自の価値

### 1. 条件検索ではなく、判断軸を提示する

ただ「英会話」「松山」「子ども」で絞るだけでは弱い。以下の判断軸を一緒に出す。

- 続けやすさ
- 初心者の入りやすさ
- 目的との一致
- 生活動線との相性
- 料金の見通し
- 体験前に確認すべきこと

### 2. 記事はランキングではなく、学びのガイドにする

既存記事は削除・置換せず、検索前後の判断を助けるガイドとして活かす。

- 「どれが人気か」より「どう選ぶか」
- 「おすすめ一覧」より「失敗しにくい見方」
- 「教室紹介」より「体験前の確認ポイント」

### 3. 掲載情報は単体ではなく、記事と結びつける

各掲載情報は `relatedGuides` で既存記事とつなぐ。これにより、ユーザーは候補カードから「選び方」へ戻れる。

### 4. 保存・比較は、候補整理の道具にする

お気に入りや比較メモは「あとで見る」だけでなく、候補の違いを言語化するために使う。

## プロダクト原則

- 既存記事のURL、本文、比較表を大きく変えない。
- 掲載情報を増やす前に、判断軸を増やす。
- 公式情報が確認できるものを優先する。
- 「今すぐ申し込み」より「自分に合うか確認する」を重視する。
- 子ども向け、大人向け、キャリア向けを同じUIに押し込まず、共通項目と固有項目で整理する。

## 実装フェーズ

### Phase 1: 土台づくり

- `listingType` で教室以外も扱えるようにする。
- `learningNeeds` と `decisionFactors` を掲載データに追加できるようにする。
- トップコピーを「検索」から「意思決定支援」に寄せる。

### Phase 2: 判断支援UI

- 「目的から探す」導線を追加する。
- 候補カードに「向いている人」「確認ポイント」を表示する。
- 比較メモに差分だけでなく「判断メモ」を加える。

### Phase 3: 学習領域の拡張

- AI・IT学習、資格学習、ビジネススキル、語学学習、副業・キャリア学習を段階的に追加する。
- 既存記事はガイドとして関連付け、新規記事は不足している判断軸だけ作る。

## 成功指標

- 検索後に比較メモへ追加する率
- 記事から掲載情報へ進む率
- 掲載情報から関連ガイドへ戻る率
- 体験・公式ページへの遷移率
- 「条件なし検索」ではなく「目的・悩み起点」の利用率
