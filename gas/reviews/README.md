# Lesson Map 口コミ受付GAS

## 導入手順

1. Googleスプレッドシート「Lesson Map｜管理」から、拡張機能 → Apps Scriptを開きます。
2. `Code.gs` の内容を貼り付けます。
3. Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に次を追加します。
   - プロパティ: `LESSONMAP_SPREADSHEET_ID`
   - 値: 対象スプレッドシートのID
4. デプロイ → 新しいデプロイ → ウェブアプリを選びます。
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
5. 発行された `/exec` URLを `js/review-config.js` の `endpoint` に設定します。
6. テスト投稿を行い、「口コミ管理」へ17列で追加されることを確認します。

投稿は「掲載候補」「未反映」で保存され、自動公開されません。
